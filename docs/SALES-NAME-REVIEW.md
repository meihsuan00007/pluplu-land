# 銷量歸戶確認清單（2026-08-31 快照）

熱銷排行是把 Google 試算表銷售紀錄的「品名」自動歸戶到官網商品後統計的。
以 2026-08-31 的紀錄快照來看：**1,855 件銷量中有 87.9% 成功歸戶到 58 個官網商品**，
剩下的品名列在下面，需要主理人幫忙決定「併入哪個商品」或「忽略」。

- 在哪裡看得到影響：娃衣選品頁的排序選單「熱銷排行：銷量由多到少」。
- 回填方式：在「主理人決定」欄填上官網商品編號（如 `#57`）或「忽略」，交給 Claude 更新對照表即可。
- 沒回填的品名目前一律**不計入**任何商品的銷量（不會算錯，只是少算）。
