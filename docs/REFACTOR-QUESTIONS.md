## 改版後你會感覺到的差異（僅告知）
1. **本機預覽方式改變**：以後不是用 Live Server 開，而是打一行指令 `npm start`，瀏覽器看 `http://localhost:4200`（README 會寫清楚）。
2. **網址結尾不再有 .html**：例如 `hamu.html` 會變成 `/hamu`。舊網址我會設定自動轉址，別人存的舊連結不會壞。
3. **Netlify 需要多一個「打包」設定**：我會把設定檔改好，你 push 之後 Netlify 會自動打包再上線。
4. **最大的好處**：頁首、頁尾、按鈕全站只有一份，永遠不會再出現「這頁改了、那頁忘了」的問題。
